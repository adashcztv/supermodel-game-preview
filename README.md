# Super Model preview — core v14 / native v30

The previous combat HUD crowded the battlefield with equally weighted panels.
This release anchors a dominant Source Cut and its Focus/chances at the lower
left, compact canonical face assists at the right, and health plus incoming
intent together above the copy. It preserves rules, saves, native contact timing
and the existing v30 scene. A read-only Assist guide pauses combat and restores
keyboard focus; Used/Full health/Full Focus explain unavailable allies.

The wrapper verifies the exact release ZIP SHA before serving it. Earlier v8,
v12 and v13 asset URLs are retained for open pages. No backend or data owners.
GitHub Actions remain manually disabled and disabled-by-project in OVH policy;
images are built by the common serialized native OVH builder.

Validation: 175 rule tests, 92 unchanged gameplay browser checks across four
encounters, and 12 final UI checks across seven Chromium/WebKit layouts.
The gameplay bundle changed only its stylesheet filename between final passes.
Physical devices, artistic/story/voice acceptance and the other three native
actors remain open. Tiny landscape prioritizes reachable commands and has a
restricted battlefield view. Model/animation work is held.

Preview: https://supermodel-preview.46.105.118.14.sslip.io/

Deployment uses the existing native rolling adapter and immutable image check.
A read-only Coolify configuration diff must be unchanged before selecting an
existing image, preventing the unexpected rebuild seen in v13.
