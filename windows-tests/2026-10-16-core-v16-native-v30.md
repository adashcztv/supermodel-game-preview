## Findings (source fixes belong to the game source, not this preview repo)

**F1 — Space re-opens a panel instead of advancing dialogue (keyboard, medium).**
After a toolbar panel (Save/Load/Log/Settings) is closed with Escape or ×, focus
returns to its toolbar button (`#quick-save` etc.). The next Space press — which
the in-game help documents as "press Space to finish a line" — activates the
focused button and re-opens the panel. Same after a mouse click on Skip/Auto: the
toolbar button keeps focus. Repro: open Save → Escape → Space → Save opens again.
Suggestion: handle Space/Enter for advancing at document level while focus is in
the quick-bar (and preventDefault), or move focus back to `#next-button` when a
panel closed by pointer, keeping Escape focus restore for keyboard users.

**F2 — Whole scene shifts by 30–50 px and stays shifted (layout, medium/high).**
`section.scene` is `overflow: hidden` but `.character-wrap` / `canvas#character`
is larger than the viewport (desktop: bottom at 818 px in a 768 px viewport;
mobile: left −30 px, right 405 px in 375 px). `overflow: hidden` is still a
programmatic scroll container, so a focus/scrollIntoView moves it:
- desktop 1024x768: after clicking the first choice, `scene.scrollTop = 50`
  (top bar cut off, empty band under the quick-bar), persisted for all following
  lines until reset;
- mobile 375x812: after "Resume the duel" screen → Load → Return here,
  `scene.scrollLeft = 30` ("SM" logo cut, dark band on the right).
Not deterministic on repeat, but observed twice with values captured.
Suggestion: `section.scene { overflow: clip; }` (cannot be scrolled
programmatically) and/or `focus({ preventScroll: true })` for focus moves, plus
reset `scrollTop/scrollLeft` on scene render.

**Observations (low, verify in source):**
- Combat: while an assist/attack animation runs, action buttons are only dimmed
  (not `disabled`/`aria-disabled`); a click in that window is silently ignored.
- After returning to a bookmark from `/?combat=1&resume=1` the URL keeps the stale
  `?combat=1&resume=1` query.
- Unity loader prints verbose `memorysetup-*` / engine logs to the console in this
  preview build.
- One early Claudia line in the arrival scene showed no portrait ~1 s after
  advancing (could be a transition; other speakers showed portraits).

Not covered: full story/endings, all combat encounters, WebKit/Firefox, physical
devices, audio listening quality.
